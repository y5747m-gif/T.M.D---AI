# تطبيق فقاعة AURA AI للهاتف (Android APK — الإصدار 2.0)

تطبيق هاتف أصلي لنظام أندرويد ينزل على الهاتف ويعمل **كفقاعة بلورية عائمة على وجه النظام** فوق جميع التطبيقات، بخلفية شفافة بالكامل 100%.

## المزايا الجديدة في الإصدار 2.0

1. **شعار وهوية بصرية جديدة كليًا (`Prism-Aura Orb`)**:
   - أيقونة بلورية متوهجة رباعية الأشعة مع هالة طيفية دوّارة وأيقونة هاتف متكيفة (`Adaptive Icon`).
2. **فقاعة فورية على وجه النظام بخلفية شفافة 100%**:
   - بمجرد التثبيت ومنح إذن الظهور فوق النظام، تستقر الفقاعة مباشرةً فوق شاشة الهاتف دون أي خلفية معتمة، وتستعيد عملها تلقائيًا بعد إعادة تشغيل الجهاز.
3. **إضاءة محيطة بحدود الشاشة بالألوان (`Ambient Screen-Edge Glow`)**:
   - عند الضغط على الفقاعة، تضيء الحواف الأربع لشاشة الهاتف بالكامل بألوان متدفقة (سيان، أزرق كهربائي، بنفسجي، وردي، ذهبي) عبر طبقة `AmbientEdgeGlowView` مسرّعة عتاديًا بـ 60 إطارًا/ثانية تمرر اللمس بالكامل للتطبيقات تحتها (`FLAG_NOT_TOUCHABLE`).
4. **شريط محادثة زجاجي في أسفل الشاشة (`Bottom Chat Capsule`)**:
   - بعد توهج حواف الشاشة مباشرةً، يصعد مكان الكتابة الزجاجي الشفاف في أسفل الشاشة مع بقاء بقية الشاشة مرئية وقابلة للمس بالكامل.
5. **بث مباشر للشاشة مع الذكاء الاصطناعي (`Live Screen AI`)**:
   - بالضغط على **«بث مباشر»** يبدأ الذكاء الاصطناعي برؤية الشاشة لحظة بلحظة عبر `MediaProjection`، ويكتشف تغيّر المشهد تلقائيًا ببصمة خفيفة `16×16` مع رد صوتي عربي أصلي عبر `TextToSpeech`.

## الحصول على ملف `TMD-AI.apk` وتثبيته

يبني GitHub Actions ملف التثبيت تلقائيًا عبر سير العمل **Build Android APK** ويرفعه تحت اسم **`TMD-AI-Android-APK`** وبداخله الملف الجاهز للتثبيت **`TMD-AI.apk`**.

أو محليًا عبر:

```bash
cd android-app
gradle assembleRelease
```

الناتج: `app/build/outputs/apk/release/app-release.apk`.
