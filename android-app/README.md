# تطبيق SPARTA AI للأندرويد (APK)

تطبيق Android أصلي لفقاعة **SPARTA AI** العائمة. عند إغلاقها تشغل مساحة الفقاعة فقط، وعند لمسها تتسع إلى نافذة دردشة فوق التطبيقات الأخرى؛ لذلك لا تبقى طبقة شفافة كبيرة تمنع لمس الهاتف. الواجهة المضمّنة داخل الـ APK تستخدم توهجًا متدرجًا بأسلوب Gemini (أزرق/بنفسجي/وردي) وتُضمَّن في حزمة التطبيق نفسها، بينما تظل طلبات الدردشة متصلةً بمسار الموقع الآمن `/api/chat`.

## الحصول على APK قابل للتثبيت

بعد رفع التعديلات، ينشئ GitHub Actions تلقائيًا workflow باسم **Build Android APK** على فرع `arena/01a0e156-t-m-d-ai` (ويمكن تشغيله يدويًا من تبويب **Actions**). نزّل artifact باسم **`TMD-AI-Android-APK`**؛ يوجد بداخله الملف **`TMD-AI.apk`** الجاهز للتثبيت.

يمكن البناء محليًا باستخدام JDK 17 وAndroid SDK 35 وGradle 8.10.2:

```bash
cd android-app
gradle assembleRelease
```

الناتج: `app/build/outputs/apk/release/app-release.apk`.

> نسخة الـ release الحالية موقّعة بمفتاح debug لتكون قابلة للتثبيت والاختبار الداخلي. قبل نشرها في متجر عام، استبدل إعداد `signingConfig` بمفتاح إصدار محفوظ بأمان ولا ترفعه إلى Git.

## تجربة المستخدم والصلاحيات

1. ثبّت `TMD-AI.apk`، واسمح بالتثبيت من المصدر الذي نزّلته منه إن طلب Android ذلك.
2. افتح التطبيق. يطلب Android أولًا إذن **الإشعارات** (Android 13+) ثم يفتح صفحة إذن **الظهور فوق التطبيقات الأخرى**.
3. فعّل "السماح بالظهور فوق التطبيقات" وعد للتطبيق: تظهر فقاعة صغيرة ثابتة قرب أسفل الشاشة وتبقى موجودة حتى عند إغلاق واجهة التطبيق من قائمة التطبيقات.
4. المس الفقاعة لتوسيع نافذة الدردشة، وقلّصها أو أغلقها لتعود فقاعة صغيرة. استخدم الإشعار الدائم أو زر **إيقاف المساعد** داخل التطبيق لإيقافها تمامًا.
5. من الفقاعة اضغط **مشاركة الشاشة**. يعرض Android نافذة `MediaProjection` الرسمية؛ لا يبدأ التقاط الشاشة إلا إذا وافقت أنت عليها.
6. أثناء المشاركة، تُرفق أحدث لقطة شاشة فقط مع الرسالة التي ترسلها لتحليلها. أوقف المشاركة من الزر نفسه أو من عناصر تحكم Android.

## الخصوصية والحدود

- لا يمكن للتطبيق، ولا ينبغي له، تجاوز إذن الظهور فوق التطبيقات أو إذن الإشعارات أو موافقة مشاركة الشاشة.
- لا يبدأ التقاط الشاشة خفيةً ولا يحتفظ بسجل فيديو: يحتفظ بآخر لقطة مضغوطة في الذاكرة فقط أثناء جلسة المشاركة، ثم يمسحها عند الإيقاف.
- يظهر إشعار Android مستمر ما دامت الفقاعة تعمل، ويتغير نصه عندما تكون مشاركة الشاشة نشطة.
- الحد الأدنى المدعوم هو Android 8.0 (API 26)، والاستهداف Android 15 / API 35.
