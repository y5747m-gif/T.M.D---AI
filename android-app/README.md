# تطبيق T.M.D AI للأندرويد (APK)

هذا هو تطبيق Android الأصلي للفقاعة العائمة فقط. يعرض المساعد فوق بقية التطبيقات، ويستخدم موافقة `MediaProjection` الرسمية لمشاركة الشاشة وإرفاق أحدث لقطة برسائل المساعد.

## الحصول على APK

من تبويب **Actions** في GitHub شغّل workflow باسم **Build Android APK**، ثم نزّل artifact باسم `TMD-AI-Android-APK`؛ بداخله الملف `TMD-AI.apk` الجاهز للتثبيت.

أو ابنِه محليًا باستخدام JDK 17 وAndroid SDK 35 وGradle 8.10.2:

```bash
cd android-app
gradle assembleRelease
```

الناتج: `app/build/outputs/apk/release/app-release.apk`.

## الاستخدام

1. ثبّت APK وافتحه.
2. اضغط **تشغيل الفقاعة العائمة** واسمح للتطبيق بالظهور فوق التطبيقات.
3. من الفقاعة اضغط **مشاركة الشاشة** ووافق على نافذة Android.
4. عند إرسال أي سؤال، تُرفق أحدث لقطة شاشة تلقائيًا لتحليلها.
5. أوقف المشاركة من الزر نفسه أو من إشعار Android، وأوقف التطبيق من شاشة التطبيق.

> موافقة الظهور فوق التطبيقات وموافقة التقاط الشاشة إلزاميتان من نظام Android ولا يجوز تجاوزهما. لا يبدأ التقاط الشاشة خفية، ويظهر إشعار دائم ما دام المساعد يعمل.

## ملاحظة النشر
